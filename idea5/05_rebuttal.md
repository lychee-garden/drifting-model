# Rebuttal：CFG 机制改进（idea2/05）

**回应对象：`05_reviewer_critique.md`**
**评级申诉：Reject → 请求重新评估**

---

## 总体回应

感谢审稿人对 CFG 机制改进方向提出的详细批评。审稿人的意见涉及现象解读的循环论证、实验设计的混淆变量、训练动态的不稳定性、部署可行性以及信息论分析的符号错误等问题。我们逐条回应，对确实存在的错误坦诚承认，对存在误读之处给出有据可查的反驳。

## 对各缺陷的逐条回应

### 缺陷一：对"最优 α=1.0"现象的解读是循环论证

审稿人指出：最简单的竞争假设是"Drifting Models 的 CFG 本身不支持推理时外插"（分布外推断），提案没有区分这两种解释。

**我们承认解释不充分，补充对照实验。**

审稿人的批评是准确的。提案对"最优 α=1.0"的解读是：训练时的 CFG 信号已被充分吸收进模型权重，因此推理时不需要额外外插。但审稿人提出的竞争假设同样合理：α > 1.0 导致性能下降，可能仅仅是因为推理时的外插超出了训练分布（分布外推断），而非条件信号本身的问题。

这两种解释对应不同的改进方向：
- 若是"条件信号饱和"假设，应增强训练时的条件信号质量；
- 若是"分布外推断"假设，应改进训练时的分布覆盖（如在训练时随机采样 $\alpha \in [0, 2]$）。

我们承认提案中未设计实验来区分这两种假设。**修订版将补充对照实验**：在训练时引入 α 随机化（$\alpha \in [0.5, 2.0]$），若此后推理时 α > 1.0 的性能恢复，则支持"分布外推断"假设；若性能仍在 α = 1.0 最优，则支持"条件信号饱和"假设。我们将根据实验结果修正解读，并据此调整后续改进方向。

### 缺陷二：负样本构造策略的实验设计无法产生可解释结论

审稿人指出：替换负样本类型同时改变了排斥信号方向和训练分布，存在不可分离的混淆变量；插值负样本在数据流形之外，可能导致 mode dropping。

**我们承认实验设计存在混淆变量，部分反驳 mode dropping 的担忧。**

审稿人关于混淆变量的批评是正确的。当我们将负样本从"无条件真实数据"替换为"跨类别生成样本"时，确实同时改变了两个因素：（1）排斥信号的语义方向；（2）训练时负样本的分布。这两个因素的效果无法通过当前实验设计分离。

**修订版将采用因子化实验设计**：固定负样本的分布来源，仅改变排斥信号的计算方式（如改变核函数的非对称性而非负样本来源），从而隔离排斥信号方向的影响。具体而言：

| 实验 | 负样本来源（固定） | 变量 | 目的 |
|------|-----------------|------|------|
| 基准 | 无条件真实数据 | — | FID=8.46 |
| 方向实验 | 无条件真实数据 | 核函数非对称性 | 分离排斥方向效果 |
| 分布实验 | 跨类别生成样本 | 负样本来源 | 分离分布效果 |

关于插值负样本导致 mode dropping 的担忧，我们有**部分反驳**：插值负样本（$y^-_\text{interp} = \lambda x_\text{real} + (1-\lambda) G(z)$，$\lambda \in (0,1)$）确实在数据流形之外，但其作用是在流形附近构造"软边界"，类似于 mixup 正则化的效果。Mode dropping 通常由过强的排斥信号导致，而非插值负样本本身。**修订版将补充实验**，监控训练过程中各模式的覆盖率，以验证是否存在 mode dropping，并设置插值强度 λ 的消融实验。

### 缺陷三：条件信号增强方向引入不可控的训练动态

审稿人指出：质量感知条件（方案 B）引入自引用反馈回路（$G \to \|V\| \to c \to G$），可能导致训练振荡；类别原型条件（方案 C）在训练后期退化为无信息常数。

**我们承认方案 B 的反馈回路风险，部分反驳方案 C 的退化问题。**

关于方案 B 的自引用反馈回路，审稿人的批评是准确的。若条件信号 $c = f(\|V\|)$，而 $V$ 又依赖于生成器输出，则形成了 $G \to V \to c \to G$ 的闭环。这种闭环在动力系统意义上可能存在不动点以外的极限环（振荡）或发散行为，提案中对此风险分析不足。

**修正方案**：引入**停止梯度**（stop-gradient）操作，切断 $\|V\|$ 到条件网络的梯度流，使条件信号仅作为前向传播的输入而非反向传播的路径。这在技术上等价于将 $\|V\|$ 视为外部观测信号而非可微变量，从而打破反馈回路，同时保留其作为训练进度代理指标的信息价值。

关于方案 C（类别原型条件）在训练后期退化为无信息常数的担忧，我们有**部分反驳**：类别原型 $\bar{\phi}_c = \mathbb{E}_{x \sim p(\cdot|c)}[\phi(x)]$ 在训练过程中会随特征编码器 $\phi$ 的更新而变化，并非静态常数。然而，审稿人的担忧有一定道理——若特征编码器在训练后期收敛，原型确实趋于稳定，条件信号的信息量下降。

**修订版将补充原型动态性的监控实验**：记录原型间余弦相似度随训练步数的变化，以及原型与当前生成样本特征之间的距离变化，量化退化是否实际发生，并据此决定是否需要引入原型的动态更新机制。

### 缺陷四：多步精炼方案违背方法核心主张

审稿人指出：推理时需要访问真实数据（`real_samples_c`），在实际部署中不可接受；NFE 从 1 增加到 3–4，放弃了单步生成优势。

**我们承认部署可行性问题，重新定位方案。**

审稿人的批评是准确的，且触及了方案的核心矛盾。多步精炼方案在推理时需要访问真实数据样本来计算漂移场 V，这在实际部署场景（在线推理、边缘设备部署）中确实不可接受。同时，NFE 从 1 增加到 3–4 确实放弃了单步生成的核心优势。

**修正方案**：将多步精炼方案重新定位为**训练时的离线数据增强**，而非推理时的在线精炼。具体而言：在训练阶段，对生成器的输出施加多步精炼（此时真实数据可用），生成高质量的伪标签，用于改善生成器的训练信号；推理时仍保持 1-NFE，不访问真实数据。这一重新定位既保留了多步精炼的质量提升效果，又不牺牲推理效率和部署可行性。

**修订版将删除"推理时多步精炼"的表述**，替换为"训练时离线精炼增强"的完整方案设计。

### 缺陷五：信息论分析存在符号错误

审稿人指出：无条件真实数据是负样本（排斥信号），提案公式将其写为正的吸引场，符号错误导致结论反转。

**我们承认符号错误，给出修正。**

审稿人的批评是正确的。在 Drifting Models 的框架中，漂移场 V 的构造为：

$$V(x) = \sum_{j} W^+_j k(x, y^+_j)(y^+_j - x) - \sum_{k} W^-_k k(x, y^-_k)(y^-_k - x)$$

其中 $y^+$ 为正样本（吸引），$y^-$ 为负样本（排斥）。在条件生成的 CFG 设置中，无条件真实数据作为**负样本**（排斥信号），因为我们希望条件生成器远离无条件分布，向条件分布靠拢。

提案第 7.1 节的公式将无条件真实数据的贡献写为正项（吸引场），这是一个符号错误。正确的公式应为：

$$V_\text{CFG}(x|c) = V_\text{cond}(x|c) + \gamma \cdot V_\text{repulsion}(x)$$

其中 $V_\text{repulsion}(x) = -\mathbb{E}_{y \sim p_\text{data}}[W^-_k(x,y)(y-x)]$ 是无条件真实数据提供的排斥项（负号使其为排斥方向）。

这一符号错误导致提案得出"CFG 防止条件生成器过度拟合到无条件分布"的结论，而正确的解释应该是"CFG 通过引入无条件真实数据作为额外排斥信号，增强了条件生成的类别区分度"。两个结论在语义上不同，对后续实验设计的指导意义也不同。

**修订版将修正所有相关公式和结论**，并重新推导基于正确符号的信息论解释。

2. 采用因子化实验设计，分离负样本来源与排斥信号方向两个混淆变量；补充 mode dropping 监控实验。
