1. **补充对照实验**：区分"条件信号饱和"与"分布外推断"两种竞争假设，解释最优 α=1.0 现象

## 1. 核心现象重新解读：最优 α=1.0

### 1.1 两种竞争假设

论文发现大模型（L/2）的最优 FID 在 α=1.0 时取得，审稿人指出原始提案的解读是循环论证。

**假设 A（原始提案）：条件信号饱和**
> 训练时的 CFG 信号已被充分吸收进模型权重，推理时不需要额外外插。

**假设 B（审稿人提出）：分布外推断**
> α > 1.0 导致性能下降，仅因为推理时的 α 超出训练时见过的范围，是分布外推断（OOD inference）。

### 1.2 区分两种假设的对照实验

**实验设计**：在训练时引入 α 随机化，扩大训练时见过的 α 范围。

| 实验 | 训练时 α 范围 | 推理时最优 α | 预期结论 |
|------|------------|------------|---------|
| 基线 | α ∈ [1.0, 3.0]（论文设置） | 1.0 | — |
| 扩展范围 | α ∈ [0.5, 4.0] | ? | 若最优 α 随范围扩大而移动 → 支持假设 B |
| 固定 α=1.0 | α = 1.0（无随机化） | 1.0 | 若 FID 不变 → 支持假设 A |

**判断标准**：
- 若扩展范围后推理时最优 α 仍为 1.0 → 支持假设 A（条件信号饱和）
- 若扩展范围后推理时最优 α 移动到 > 1.0 → 支持假设 B（分布外推断）

### 1.3 修正后的信息论解释

**原始提案的符号错误**：将无条件真实数据的贡献写为正的吸引场，但它实际上是**负样本（排斥信号）**。

**正确的 CFG 机制解释**：

在 Drifting Models 的 CFG 设置中，漂移场为：

$$V_\text{CFG}(x|c) = V_\text{cond}(x|c) + \gamma \cdot V_\text{repulsion}(x)$$

其中：
- $V_\text{cond}(x|c)$：条件正样本（同类真实数据）提供的吸引场
- $V_\text{repulsion}(x) = -\mathbb{E}_{y \sim p_\text{data}}[W^-_k(x,y)(y-x)]$：无条件真实数据作为**负样本**提供的排斥场（负号使其为排斥方向）

**正确结论**：CFG 通过引入无条件真实数据作为额外排斥信号，**增强了条件生成的类别区分度**，而非"防止过度拟合到无条件分布"。

这一区别对实验设计有重要指导意义：改进 CFG 的方向应是**优化排斥信号的质量和方向**，而非增强吸引信号。

## 2. 方向一：负样本构造策略（因子化实验设计）

### 2.1 混淆变量的分离

原始提案的实验设计存在根本性混淆：替换负样本类型同时改变了（1）排斥信号方向和（2）训练分布。

**修订方案：因子化实验设计**

固定负样本的分布来源，仅改变排斥信号的计算方式：

| 实验 | 负样本来源（固定） | 变量 | 目的 |
|------|-----------------|------|------|
| G0 | 无条件真实数据（基线） | — | FID=8.46 |
| G1 | 无条件真实数据 | 核函数非对称性（Q-K 分离） | 分离排斥方向效果 |
| G2 | 跨类别生成样本 | 负样本来源 | 分离分布效果 |
| G3 | 跨类别真实数据 | 负样本来源（控制生成质量） | 排除生成质量影响 |

**G1 vs G2 的对比**：
- G1 改变排斥方向，不改变分布来源 → 测量排斥方向的独立效果
- G2 改变分布来源，不改变核函数 → 测量分布来源的独立效果

### 2.2 跨类别负样本的理论分析

**跨类别生成样本作为负样本的动机**：

当前设计中，负样本来自同类别的生成样本（$y^- \sim q_\theta(\cdot|c)$）。这意味着排斥信号只推离"同类别的错误生成"，而不推离"其他类别的混淆区域"。

引入跨类别负样本（$y^- \sim q_\theta(\cdot|c'), c' \neq c$）可以：
- 增强类别边界的清晰度
- 减少类别混淆（生成的猫被误认为狗）

**风险**：跨类别负样本改变了训练分布，可能引入偏差。通过 G3（跨类别真实数据）控制生成质量的影响。

### 2.3 插值负样本的 Mode Dropping 监控

原始提案的插值负样本（$y^-_\text{interp} = \lambda x_\text{real} + (1-\lambda) G(z)$）可能导致 mode dropping。

**修订方案**：
- 保留插值负样本实验，但添加 mode dropping 监控
- 监控指标：各类别的生成样本数量分布（应均匀），以及各类别 FID 的方差
- 设置 λ 的消融实验（λ ∈ {0.1, 0.3, 0.5, 0.7, 0.9}）

## 3. 方向二：条件信号增强（修订版）

### 3.1 方案 B 的反馈回路修正

**原始方案 B（质量感知条件）**：
$$x = G(z, c, \alpha, \|V\|_\text{batch})$$

**问题**：$G \to V \to \|V\| \to c \to G$ 形成自引用反馈回路，可能导致训练振荡。

**修正方案**：引入 stop-gradient 切断反馈回路：

```python
# 修正版：stop-gradient 打破反馈回路
V_norm = compute_V_norm(x_gen, y_pos, y_neg)  # 计算 ||V||
V_norm_sg = V_norm.detach()  # stop-gradient：||V|| 不参与反向传播

# 将 ||V|| 作为外部观测信号（非可微变量）
x = generator(z, class_label, alpha, V_norm_sg)
```

**理论保证**：stop-gradient 将 $\|V\|$ 视为外部观测信号，打破了 $G \to V \to c \to G$ 的闭环，训练动态退化为标准的条件生成，稳定性有保证。

### 3.2 方案 C 的原型动态性监控

**原始方案 C（类别原型条件）**：
$$x = G(z, c, \alpha, \bar{\phi}_c), \quad \bar{\phi}_c = \mathbb{E}_{x \sim p(\cdot|c)}[\phi(x)]$$

**审稿人担忧**：训练后期 $\bar{\phi}_c$ 趋于稳定，条件信号退化为无信息常数。

**修订方案**：
1. 添加原型动态性监控：记录原型间余弦相似度随训练步数的变化
2. 若原型趋于稳定（相似度变化 < 1%），引入**动态原型更新**：
   $$\bar{\phi}_c^{(t)} = (1-\beta) \bar{\phi}_c^{(t-1)} + \beta \cdot \frac{1}{N_c} \sum_{x \sim p(\cdot|c)} \phi(x)$$
   其中 $\beta$ 为动量系数（建议 0.01），使原型随特征编码器的更新而缓慢变化。

### 3.3 新增方案：训练进度条件（低风险）

将当前训练步数（归一化到 [0,1]）作为额外条件，无反馈回路风险：

```python
# 训练进度条件（无反馈回路）
progress = torch.tensor(current_step / total_steps)  # 标量，外部输入
x = generator(z, class_label, alpha, progress)
```

**动机**：允许生成器在训练初期（progress 小）采用更保守的策略，训练后期（progress 大）采用更精细的策略。

**实验设计**：

| 实验 | 条件信号 | 预期 FID |
|------|---------|---------|
| C0 | 基线（无额外条件） | 8.46 |
| C1 | 训练进度条件 | 预期 8.0–8.3 |
| C2 | 质量感知条件（+stop-gradient） | 预期 7.8–8.2 |
| C3 | 类别原型条件（+动态更新） | 预期 7.5–8.0 |

## 4. 方向三：无条件生成改进

### 4.1 类别平衡的无条件队列

当前全局队列（1000 个样本）混合了所有类别，可能存在类别不平衡。

**修订方案**：确保全局队列中每个类别的样本数量相等（每类 1000/1000 = 1 个 → 每类 10 个，共 10000 个）。

```python
class BalancedUnconditionalQueue:
    def __init__(self, num_classes=1000, samples_per_class=10):
        self.queues = {c: deque(maxlen=samples_per_class)
                       for c in range(num_classes)}
        self.num_classes = num_classes

    def push(self, samples, labels):
        for sample, label in zip(samples, labels):
            self.queues[label.item()].append(sample)

    def sample(self, n):
        per_class = max(1, n // self.num_classes)
        samples = []
        for c in range(self.num_classes):
            if len(self.queues[c]) > 0:
                k = min(per_class, len(self.queues[c]))
                samples.extend(random.sample(list(self.queues[c]), k))
        random.shuffle(samples)
        return torch.stack(samples[:n])
```

### 4.2 队列大小消融

论文固定队列大小为 1000，未经充分消融。

| 实验 | 队列大小 | 预期 FID |
|------|---------|---------|
| Q0 | 1000（基线） | 8.46 |
| Q1 | 500 | ? |
| Q2 | 2000 | ? |
| Q3 | 5000 | ? |

## 5. 方向四：推理时引导重新设计

### 5.1 删除多步精炼方案（推理时版本）

原始提案的推理时多步精炼存在两个根本问题：
1. NFE 从 1 增加到 3–4，放弃单步生成优势
2. 推理时需要访问真实数据（`real_samples_c`），实际部署不可接受

**修订决定**：完全删除推理时多步精炼方案。

### 5.2 训练时离线精炼增强（替代方案）

将多步精炼重新定位为**训练时的离线数据增强**：

```python
# 训练时：对生成器输出施加多步精炼，生成高质量伪标签
# （此时真实数据可用，不影响推理时的 1-NFE 特性）

def generate_refined_samples(generator, real_samples, n_refine_steps=3):
    """训练时离线精炼，生成高质量伪标签"""
    with torch.no_grad():
        x = generator(z, c, alpha=1.0)  # 初始单步生成
        for _ in range(n_refine_steps):
            V = compute_V(x, real_samples, x.detach())  # 真实数据可用
            x = x + 0.1 * V  # 精炼步骤
    return x  # 高质量伪标签，用于改善训练信号

# 将精炼样本加入正样本队列，提升训练信号质量
refined = generate_refined_samples(generator, real_batch)
sample_queue.push(refined, labels)  # 作为额外正样本
```

**优势**：
- 推理时仍保持 1-NFE，不访问真实数据
- 训练时利用精炼样本提升正样本质量，间接改善生成器

### 5.3 特征空间引导（低风险推理时方案）

在推理时，使用特征编码器的梯度引导生成，无需访问真实数据：

$$x_\text{guided} = x + \eta \nabla_x \log k(\phi(x), \bar{\phi}_c)$$

其中 $\bar{\phi}_c$ 是预先计算并缓存的类别原型（训练结束后固定）。

**优势**：
- 推理时不访问真实数据（只使用预缓存的原型）
- NFE 仍为 1（梯度引导是单步操作）
- 不破坏训练时学到的分布

## 7. 理论框架：CFG 的信息论解释（修正版）

### 7.1 无条件负样本的正确作用

在 Drifting Models 的 CFG 框架中，训练目标为：

$$\tilde{q}(\cdot|c) = (1-\gamma) q_\theta(\cdot|c) + \gamma p_\text{data}(\cdot|\varnothing)$$

目标是使 $\tilde{q}(\cdot|c) = p_\text{data}(\cdot|c)$，即：

$$q_\theta(\cdot|c) = \alpha \cdot p_\text{data}(\cdot|c) - (\alpha-1) \cdot p_\text{data}(\cdot|\varnothing)$$

其中 $\alpha = 1/(1-\gamma) \geq 1$。

**信息论解释**：无条件真实数据作为负样本，提供了一个"全局排斥场"，将条件生成样本推离无条件分布的高密度区域，从而增强类别区分度。

### 7.2 最优 α=1.0 的两种解释（修正后）

**假设 A（条件信号饱和）**：
- 大模型（L/2）容量足够，能直接学习 $p(x|c)$
- 训练时的 CFG 信号（无条件负样本）已将类别信息充分编码进权重
- 推理时 α=1.0 对应"无额外外插"，即直接使用学到的条件分布

**假设 B（分布外推断）**：
- 训练时 α ∈ [1.0, 3.0]，推理时 α > 3.0 是 OOD
- 但最优 α=1.0 < 训练范围的最小值，说明即使在训练范围内，α=1.0 也是最优
- 这更支持假设 A，而非假设 B

**修订立场**：基于上述分析，假设 A 更可能正确，但仍需通过 H1/H2 实验验证。
