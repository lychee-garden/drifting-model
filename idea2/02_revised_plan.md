# 像素空间生成方案（修订版）

## 修订说明

本方案完整吸收审稿人五项批评及作者回应，核心修订如下：

1. **删除"4.5% 差距"的线性外推论证**，替换为实测 FID-训练轮数曲线
2. **重新定位核心论点**：从"VAE 不是必要的"改为"特征压缩与分布正则化解耦的架构价值"
3. **补充三组控制实验**，区分多编码器融合提升的来源假设
4. **严格分离架构改进与编码器改进实验**，确保结果可归因
5. **重新定位竞争基准**，聚焦同等 NFE 约束下的方法对比

## 1. 核心论点重新定位

### 1.1 放弃"VAE 不是必要的"

原始提案的核心论点存在根本性逻辑矛盾：声称"不依赖 VAE"，却引入参数量更大的 DINOv2（307M）替代 VAE（80M）。

**修订后的核心论点：**

> **特征压缩（降维）与分布正则化（KL 约束）的解耦，带来了架构设计的灵活性。**

VAE 在潜空间生成框架中耦合了两个功能：
- **特征压缩**：将高维像素空间压缩到低维潜空间
- **分布正则化**：KL 散度约束使潜空间具有良好的插值性质

这种耦合使生成质量上限被 VAE 重建误差约束（SD-VAE 的 LPIPS ≈ 0.05）。

像素空间框架**解耦**了这两个功能：
- 特征编码器只承担特征压缩（无 KL 约束）
- 生成器直接在像素空间优化分布匹配

**解耦的价值**：特征编码器可以自由选择最适合漂移场估计的几何结构，不受 VAE 重建目标的约束。

### 1.2 VAE 重建误差的定量分析

| 方法 | 信息瓶颈来源 | 上限约束 |
|------|------------|---------|
| 潜空间 Drifting | SD-VAE 重建误差（LPIPS≈0.05） | 解码器质量 |
| 像素空间 Drifting | 特征编码器感知粒度 | 编码器质量 |
| 像素空间 + DINOv2 | DINOv2 特征压缩 | 编码器质量（更高） |

像素空间框架的上限约束来自编码器感知粒度，而非重建误差，理论上可以通过更强的编码器持续提升。

## 2. 实验一：训练轮数的实测曲线（替换外推）

### 2.1 实验设计

**删除**原始提案中"640→1280 轮 FID 从 1.61 降至 1.3–1.5"的线性外推。

**替换为**：直接训练至 1280 轮，绘制完整 FID-训练轮数曲线。

| 实验 | 配置 | 检查点 | 目的 |
|------|------|--------|------|
| P0 | 像素空间，MAE w=640+cls ft，640 轮 | 每 80 轮 | 复现论文 FID=1.61 |
| P1 | 像素空间，MAE w=640+cls ft，1280 轮 | 每 80 轮 | 实测收敛行为 |
| P2 | 像素空间，MAE w=640+cls ft，2560 轮 | 每 160 轮 | 测试是否饱和 |

**成功标准**：
- P1 实测 FID < 1.5：证明像素空间在充分训练后可与潜空间持平
- 曲线斜率分析：若 1280→2560 轮的改善 < 5%，则认为收敛

**GPU 估算**：P1 约 400 小时，P2 约 800 小时

## 3. 实验二：多编码器融合的控制变量实验

### 3.1 三种竞争假设

论文已验证 ResNet-MAE + ConvNeXt-V2 组合将 100 轮 FID 从 9.35 降至 3.70，但原因不明：

| 假设 | 描述 |
|------|------|
| A：几何互补性 | 两个编码器的特征空间各向同性互补，融合后内在维度降低 |
| B：ConvNeXt-V2 本身更强 | 提升主要来自 ConvNeXt-V2，与融合无关 |
| C：特征维度增加 | 拼接后维度翻倍，信息量增加，与互补性无关 |

### 3.2 控制变量实验设计

**实验 F1：维度控制（排除假设 C）**

| 设置 | 操作 | 预期 FID（100 轮） |
|------|------|-----------------|
| 基线 | MAE w=640（dim=640） | 9.35 |
| 升维 | MAE w=640 + 线性投影到 dim=1280 | ? |
| 融合 | MAE w=640 + ConvNeXt-V2（dim≈1280） | 3.70 |

若升维后 FID 不改善（接近 9.35），则排除假设 C。

**实验 F2：强度控制（分离假设 B）**

| 设置 | 操作 | 预期 FID（100 轮） |
|------|------|-----------------|
| 单独 MAE | MAE w=640 | 9.35 |
| 单独 ConvNeXt-V2 | ConvNeXt-V2 only | ? |
| 融合 | MAE + ConvNeXt-V2 | 3.70 |

若单独 ConvNeXt-V2 的 FID 接近 3.70，则假设 B 成立，融合的价值有限。

**实验 F3：随机融合（验证互补性来源）**

| 设置 | 操作 | 预期 FID（100 轮） |
|------|------|-----------------|
| 真实融合 | MAE + ConvNeXt-V2 | 3.70 |
| 随机融合 | MAE + 随机初始化 ConvNeXt-V2 | ? |

若随机融合 FID 接近真实融合，则互补性来自架构差异（卷积 vs 残差），而非训练目标差异。

### 3.3 几何分析（若假设 A 成立）

若实验支持几何互补性假设，进一步分析：
- 计算 MAE 特征矩阵和 ConvNeXt-V2 特征矩阵的奇异值分布
- 计算融合特征矩阵的奇异值分布
- 量化各向同性改善程度（奇异值分布的均匀性）

## 4. 实验三：编码器替换（严格消融）

### 4.1 实验顺序原则

**严格分离**：编码器改进实验与架构改进实验不同时进行，确保结果可归因。

**第一步**：固定生成器架构（DiT-L/16），只改变编码器。

| 实验 | 编码器 | 生成器 | 目的 |
|------|--------|--------|------|
| E0 | MAE w=640 + cls ft | DiT-L/16（固定） | 基线 FID=1.61 |
| E1 | MAE + ConvNeXt-V2 | DiT-L/16（固定） | 编码器融合效果 |
| E2 | DINOv2 ViT-L/14（冻结） | DiT-L/16（固定） | 强编码器效果 |
| E3 | MAE + ConvNeXt-V2 + DINOv2 | DiT-L/16（固定） | 三编码器融合 |

**第二步**（仅在 E 系列完成后）：固定最优编码器，改变生成器架构。

### 4.2 DINOv2 接入方案

像素空间（256×256）直接使用 DINOv2，无需 VAE decoder：

```python
class DINOv2PixelEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        self.backbone = torch.hub.load('facebookresearch/dinov2', 'dinov2_vitl14')
        for p in self.backbone.parameters():
            p.requires_grad = False  # 第一阶段冻结

    def forward(self, x):
        # x: (B, 3, 256, 256)
        # DINOv2 ViT-L/14: patch_size=14，256/14≈18.3，需 resize
        x = F.interpolate(x, size=(252, 252), mode='bilinear', align_corners=False)
        # 252 = 14 × 18，整除
        feats = self.backbone(x)  # (B, 1024) CLS token
        return feats  # 由 drifting.py 的 feature normalization 处理
```

**注意**：256 不是 14 的整数倍，resize 到 252（14×18）避免边界效应。

## 5. 实验四：生成器架构改进（严格消融）

### 5.1 与编码器实验严格分离

**前提**：完成 E 系列实验，确定最优编码器后，再进行架构实验。

**固定编码器**（使用 E 系列最优结果），只改变生成器：

| 实验 | 生成器 | 编码器（固定） | 目的 |
|------|--------|-------------|------|
| A0 | DiT-L/16（基线） | E 系列最优 | 架构基线 |
| A1 | DiT-L/16 + 局部-全局注意力 | E 系列最优 | 注意力改进效果 |
| A2 | DiT-L/16 + U-Net 跳跃连接 | E 系列最优 | 跳跃连接效果 |
| A3 | A1 + A2 | E 系列最优 | 组合效果 |

### 5.2 局部-全局注意力的像素空间动机

像素空间生成（256×256，patch=16×16，N=256 tokens）与潜空间（32×32，patch=2×2，N=256 tokens）的 token 数相同，但语义密度不同：

- 像素空间每个 token 覆盖 16×16 像素，包含更多局部纹理信息
- 全局注意力对所有 token 平等处理，可能过度平滑局部细节

局部-全局混合注意力针对这一特点设计，是**像素空间特有的需求**，而非通用改进。

## 6. 竞争基准重新定位

### 6.1 放弃"FID < 1.0"的绝对目标

原始提案的"FID < 1.0"在 2026 年缺乏竞争力。

**修订后的竞争基准**：

**核心问题**：在相同 NFE=1 约束下，像素空间 Drifting Models 是否能超越同等规模的潜空间 Drifting Models？

| 对比维度 | 潜空间 Drifting（L/2） | 像素空间 Drifting（L/16） |
|---------|---------------------|----------------------|
| FID | 1.54 | 1.61 |
| NFE | 1 | 1 |
| 参数量 | 463M+49M（含 VAE） | 464M（无 VAE） |
| 训练轮数 | 1280 | 640（未充分训练） |

**目标**：在 1280 轮训练后，像素空间 FID ≤ 1.54（与潜空间持平）。

### 6.2 与同类单步方法的对比

| 方法 | 空间 | NFE | FID |
|------|------|-----|-----|
| EPG-L/16 | 像素 | 1 | 8.82 |
| StyleGAN-XL | 像素 | 1 | 2.30 |
| GigaGAN | 像素 | 1 | 3.45 |
| **Drifting Model L/16（论文）** | 像素 | 1 | **1.61** |
| **Drifting Model L/16（修订目标）** | 像素 | 1 | **≤1.54** |

在像素空间单步生成方法中，Drifting Models 已经是 SOTA，修订目标是进一步与潜空间方法持平。
